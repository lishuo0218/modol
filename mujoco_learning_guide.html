从入门到精通：一份为机器人开发者定制的深度技术参考手册。

1. 基础概念

1.1简介与文件结构

MJCF (MuJoCo XML File) 是一种基于 XML 的分层建模语言。不同于 URDF 的平铺式结构，MJCF 采用嵌套树状结构，这使得相对坐标的定义非常直观。

核心原则： 子物体的坐标系总是相对于父物体的坐标系定义的。这大大简化了多关节机器人的建模工作。

标准文件骨架

<mujoco model="my_robot">
    <!-- 1. 编译与仿真选项 -->
    <compiler angle="degree" />
    <option timestep="0.002" />

    <!-- 2. 资源库 (纹理、网格、材质) -->
    <asset>...</asset>

    <!-- 3. 默认属性类 (类似 CSS class) -->
    <default>...</default>

    <!-- 4. 物理世界 (核心) -->
    <worldbody>
        <body name="base">
            <joint ... />
            <geom ... />
            <body name="link1"> ... </body>
        </body>
    </worldbody>

    <!-- 5. 驱动与传感器 -->
    <actuator>...</actuator>
    <sensor>...</sensor>
</mujoco>

1.2坐标系与变换 (Coordinate Systems)

理解 MuJoCo 的坐标变换是建模的关键。每个 body 都有自己的局部坐标系 (Frame)。

关键属性

  • pos="x y z": 子物体原点相对于父物体原点的位移。
  • quat="w x y z": 四元数旋转 (MuJoCo 内部首选)。
  • euler="rx ry rz": 欧拉角旋转 (建模时更直观)。
注意： 默认情况下，MuJoCo 的欧拉角顺序是 "xyz" (Extrinsic)。如果需要改变，可以在 <compiler eulerseq="..."/> 中设置。
2. 物理建模

2.1刚体 (Body) Core

<body> 是运动学树的节点。它本身没有质量或形状，仅仅是一个坐标系框架 (Frame) 和惯性容器。

刚体的质量和惯性通常由其内部的 <geom> 自动计算得出，除非显式使用 <inertial> 标签指定。

2.2几何体 (Geom) Core

<geom> 定义了物体的形状、碰撞属性和视觉外观。

常用类型 (type)

类型尺寸参数 (size)说明
box半长 (x, y, z)长方体，size="0.1 0.2 0.3" 代表长0.2, 宽0.4, 高0.6
sphere半径球体
cylinder半径, 半高圆柱体
capsule半径, 半高胶囊体 (两端半球，中间圆柱)，比圆柱体碰撞更稳定
mesh缩放 (x, y, z)引用 <asset> 中的网格资源
plane半长 (x, y), 间距无限平面 (通常做地面)

关键物理属性

  • friction="滑动 滚动 扭转": 摩擦系数。通常只设置第一个 (滑动摩擦)，如 1.0。
  • density: 密度 (默认 1000 kg/m³)。用于自动计算质量。
  • mass: 显式指定质量 (会覆盖 density)。
  • group: 视觉分组 (0-2 可见，3+ 通常隐藏或用于辅助)。

2.3关节 (Joint) Core

关节定义了自由度 (DOF)。如果一个 Body 没有关节，它将与父级固连 (焊接)。

关节类型

  • hinge: 旋转关节 (1 DOF)。最常用。需指定 axis (旋转轴)。
  • slide: 滑动关节 (1 DOF)。直线运动。
  • ball: 球铰 (3 DOF)。旋转自由，无位移。
  • free: 自由关节 (6 DOF)。允许物体在空间中自由漂浮 (如无人机、未固定的物体)。

动力学属性

  • range="min max": 运动范围限制 (弧度或米)。
  • damping: 阻尼系数 (粘性摩擦)。防止关节无限摆动。
  • stiffness: 弹簧刚度。设为非0值会使关节像弹簧一样回中。
  • armature: 转子惯量。重要技巧：给关节加少量 armature (如 0.01) 可以显著提高仿真稳定性。
3. 高级物理

3.1碰撞过滤 (Advanced Collision) Advanced

MuJoCo 提供了强大的碰撞过滤机制，通过位掩码 (Bitmask) 控制。

Contype 与 Conaffinity

两个物体 A 和 B 发生碰撞的条件是：

(A.contype & B.conaffinity) || (B.contype & A.conaffinity) != 0
  • contype: "我是什么类型的物体" (ID)。
  • conaffinity: "我能撞什么类型的物体" (Mask)。

示例场景

<default>
    <!-- 机器人(1): 能撞地面(2) -->
    <default class="robot">
        <geom contype="1" conaffinity="2"/>
    </default>
    
    <!-- 地面(2): 能撞机器人(1) -->
    <default class="floor">
        <geom contype="2" conaffinity="1"/>
    </default>
    
    <!-- 纯视觉物体: 谁都不撞 -->
    <default class="visual_only">
        <geom contype="0" conaffinity="0"/>
    </default>
</default>

3.2求解器参数 (Solref & Solimp) Advanced

这是控制接触"软硬度"的核心参数，直接影响仿真的稳定性。

Solref (Solver Reference)

格式: solref="timeconst dampratio"

  • timeconst (时间常数): 刚度指标。值越小越硬。例如 0.001 非常硬，0.02 像硬橡胶。
  • dampratio (阻尼比): 1.0 为临界阻尼 (无震荡)，<1 欠阻尼 (弹簧)，>1 过阻尼 (海绵)。

Solimp (Solver Impedance)

控制约束力随穿透深度变化的曲线。通常使用默认值，但在抓取任务中可能需要调整以增加摩擦稳定性。

4. 驱动与感知

4.1执行器 (Actuator)

没有执行器，机器人只能随重力摆动。

  • Position (位置伺服): 输入为目标角度。
    <position joint="j1" kp="100"/> (kp 是 P 增益)
  • Velocity (速度伺服): 输入为目标角速度。
    <velocity joint="j1" kv="10"/>
  • Motor (力矩控制): 输入为直接力矩/力。
    <motor joint="j1" gear="1"/> (最接近真实电机电流控制)

4.2肌腱 (Tendon) Advanced

用于模拟复杂的传动系统。

  • fixed: 固定传动比耦合。例如：模拟机械手手指的耦合运动 (一个电机驱动两个关节)。
  • spatial: 空间肌腱。模拟绳索穿过滑轮 (site) 的路径。可以自动计算绳索长度变化并施加力。

4.3传感器 (Sensor)

定义仿真器输出的观测数据。

<sensor>
    <!-- 关节传感器 -->
    <jointpos joint="knee"/>
    <jointvel joint="knee"/>

    <!-- IMU (需绑定到 site) -->
    <accelerometer site="imu_site"/>
    <gyro site="imu_site"/>

    <!-- 接触传感器 (Touch) -->
    <touch site="fingertip" name="touch_sensor"/>
    
    <!-- 力/力矩传感器 (F/T) -->
    <force site="wrist"/>
    <torque site="wrist"/>
</sensor>
5. 系统设置

5.1资源与渲染 (Asset)

管理复用的资源，如网格 (Mesh)、纹理 (Texture) 和材质 (Material)。

  • <mesh file="part.stl" />: 导入 STL/OBJ 模型。
  • <texture type="skybox" ... />: 定义天空盒。
  • <material name="mat" rgba="1 0 0 1" />: 定义材质颜色和反光属性。

5.2仿真选项 (Option)

  • timestep: 积分步长。默认 0.002 (2ms)。对于高速碰撞或复杂机器人，可能需要减小到 0.001 或更小。
  • integrator: 积分器类型。Euler (一阶) 或 RK4 (四阶)。Euler 稳定性更好，通常首选。
  • gravity: 重力向量。默认 "0 0 -9.81"。
